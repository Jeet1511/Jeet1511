## Projects

### [ExpressBasket](https://github.com/Jeet1511/ExpressBasket)
Full-featured e-commerce platform. Product listings, cart management, and a complete checkout flow — backed by a clean REST API with middleware-based auth and a sensible route structure built for scale.

`Node.js` `Express.js` `JavaScript` `MongoDB`

---

### [Monitor](https://github.com/Jeet1511/Monitor)
Real-time server monitoring dashboard. The backend streams system metrics live via WebSocket; the React frontend renders them in a clean UI. Built it because I wanted something lightweight I could self-host instead of paying for an APM tool.

`React` `Node.js` `MongoDB` `Socket.io`

---

### [EliteZero](https://github.com/Jeet1511/EliteZero)
Discord bot for community engagement and moderation. Modular command handler architecture — each feature lives in its own file so adding new commands doesn't mean touching core logic.

`Node.js` `Discord.js` `JavaScript`

---

### [Portfolio](https://github.com/Jeet1511/Portfolio)
Personal portfolio built without a framework. Plain HTML, CSS, and vanilla JavaScript — because not every problem needs React, and it's good to remember that.

`HTML5` `CSS3` `JavaScript`
